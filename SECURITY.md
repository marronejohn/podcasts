# Security Policy

## Reporting a Vulnerability

If you find a security issue in Podcasts, please report it privately rather than opening a public issue.

- Use GitHub's "Report a vulnerability" button under the Security tab of this repository, or
- Email John Marrone via marronejohn@users.noreply.github.com.

Please include a description of the issue, steps to reproduce it, and your assessment of its impact. You can expect an initial response within a few days.

## Supported Versions

Only the latest release (the current v1.x APK and its source) is supported with security fixes.

## Scope

Podcasts is a small, offline-first podcast catcher. Reports are most useful for:

- Anything that mishandles downloaded content or feed data (parsing, storage, network)
- Permission misuse or privacy issues
- Anything that could let a third party execute code on a user's device

Issues in third-party components should be reported upstream.
